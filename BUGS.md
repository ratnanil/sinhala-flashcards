## 1. Wrong German article — *der* Mango, *der* Ananas

| Card | Current | Correct |
|------|---------|---------|
| mango | `der Mango` | `die Mango` |
| pineapple | `der Ananas` | `die Ananas` |

**Root cause:** `enriched/ankiweb-vocab/translations.csv` — LLM assigned wrong grammatical gender.

**Pipeline step:** `generate_translations.py` (Ollama) writes to `enriched/ankiweb-vocab/translations.csv`;
`build_deck.py` reads it to fill the German column; `generate_audio.py` reads it to
synthesize TTS.

**Fix:**
1. Edit `enriched/ankiweb-vocab/translations.csv`: correct the two entries.
2. Delete the stale TTS files `enriched/ankiweb-vocab/tts/audio/mango_de.mp3` and `enriched/ankiweb-vocab/tts/audio/pineapple_de.mp3`.
3. Run `make audio` to regenerate them, then `make deck` to rebuild.

## 4. Wrong image for *morgen* (tomorrow)

**Symptom:** The card for `morgen` / හෙට shows a sunrise image.

**Root cause:** `images/tomorrow.png` was generated by `generate_images.py` using Ollama +
Twemoji. The LLM picked a sunrise emoji (sunrise over horizon) which evokes *der Morgen*
(morning) rather than *morgen* (tomorrow). Additionally, the German word *morgen* is
ambiguous (means both "tomorrow" and "morning"), making a learner unsure which sense the
image represents.

**Image key:** The key used in `build_deck.py` is the `english` column value, i.e.
`"tomorrow"` → `enriched/ankiweb-vocab/images/tomorrow.png`.

**Fix:** Delete `enriched/ankiweb-vocab/images/tomorrow.png` and either:
- (a) Regenerate: `python scripts/generate_images.py --source parsed/ankiweb-vocab/cards.csv`
      (Ollama may pick a different emoji; results vary — may need a few tries).
- (b) Manually replace with a more unambiguous image (e.g. a calendar page emoji).
Then run `make deck` to copy the new image into the Media folder.

## 6. German TTS pronounced with English accent

**Symptom:** Some German TTS audio is read with English pronunciation.
Known example: `erzählen` pronounced as *erselen* instead of *ɛɐ̯ˈtsɛːlən*.

**Root cause:** The voice used is `de-DE-SeraphinaMultilingualNeural` (set in the
Makefile `audio` target). Being a multilingual model, it occasionally falls back to
English phonology for certain German words — particularly those with umlauts or sounds
absent in English.

**Likely affected cards:** Any word with German-specific phonemes that have no English
equivalent (ä, ö, ü, ch, z as /ts/, etc.). `erzählen` is a confirmed case; others may
be affected but have not been audited yet.

**Fix (option A — switch voice, regenerate all):**
1. In the Makefile `audio` target, change the voice to a monolingual German voice, e.g.:
   `--voice de-DE-KatjaNeural` (female) or `--voice de-DE-ConradNeural` (male).
2. Delete all `*_de.mp3` files in `enriched/ankiweb-vocab/tts/audio/`.
3. Delete all `lang=de` rows from `enriched/ankiweb-vocab/tts/registry.csv`.
4. Run `make audio && make deck`.

**Fix (option B — patch known-bad cards only):**
1. For each known-bad card, delete its `enriched/ankiweb-vocab/tts/audio/<english>_de.mp3` file and its row in
   `enriched/ankiweb-vocab/tts/registry.csv`.
2. Change the voice in the Makefile, then run `make audio && make deck`.
   (New voice will only generate what is missing.)
